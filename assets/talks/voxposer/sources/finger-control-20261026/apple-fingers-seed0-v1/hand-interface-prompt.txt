This robot has a Panda arm and a LEAP hand, not a two-finger parallel gripper.
get_hand_state() returns a dictionary with 'joints', 'digits', and 'palm'.
Each joints[name] entry contains angle_rad, target_rad, lower_rad, upper_rad,
and actuator. The 16 names are finger_0, finger_1, finger_2 and thumb, each
followed by .proximal, .lateral, .middle or .distal. Finger numbers follow
their geometric order on the palm. Proximal bends at the palm, middle and
distal bend farther along the digit. Finger lateral joints spread sideways;
the thumb lateral joint twists. Positive bending closes toward the palm.
digits[name]['pad_position_world_m'] is the current fingertip position in metres.
palm contains position_world_m and quaternion_wxyz. All these are measured
states; queries do not move the robot. They are dictionaries, not attributes
of detect() observations. Do not assume other object attributes are present.
vec2quat(direction) is an alias of the existing pointat2quat(direction).
It returns a wxyz quaternion whose local +z axis points along the given
nonzero world direction. Roll follows the existing pointat2quat construction;
it is not an object-axis transform or a command to turn an object.
The ordinary VoxPoser execute() and gripper-map interfaces remain available.
Use only the listed APIs and the functions shown in the original examples.

You additionally have set_hand_joint_targets(targets), where targets is a
dictionary from any of the 16 names in get_hand_state()['joints'] to absolute
joint angles in radians. All 16 joints can be selected independently.
Unspecified joints keep their current commanded target. Targets must lie
inside the reported lower_rad and upper_rad; invalid requests raise an error.
The command interpolates the selected targets while holding the current arm
pose. It also remembers the resulting hand posture as the closed posture for
subsequent Cartesian moves and gripper-map close commands. Open commands
restore the original open posture; close commands reuse the latest specified
posture. You may query current joint and fingertip states and revise targets
throughout the program. This API supplies no grasp planner or posture examples.
