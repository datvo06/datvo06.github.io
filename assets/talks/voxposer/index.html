Download all artifacts · Run details · VoxPoser code

These are initial trials of the released VoxPoser RLBench demo on rolly, not a reproduction of the paper's aggregate results or a comparison against the LEAP YCB tasks. The demo uses RLBench object masks. Its default config performs one outer planning pass; VoxPoser's separate object-pushing path uses sampling MPC. We retained upstream prompts, planner and controller, and used GPT-4.1 because the original GPT-4 endpoint rejected requests. Success is latched when an executed TaskEnvironment.step returns positive sparse reward. The saucepan trial reaches that condition before the instruction finishes; an earlier final-state-only check missed it. Both recordings are replays using cached LLM responses. Replay wall times were 13.94 seconds for saucepan and 9.81 seconds for button; these exclude initial LLM generation and are not comparable performance measurements. The videos show 278 and 236 native simulation steps at 20 Hz, respectively, at the original 128 by 128 recording resolution. The artifact bundle includes both videos, initial and final images, exact configs, normalized outcomes and a manifest with upstream revisions and video checksums. Normalized outcomes omit an unreliable observation variation field from the original runner output.
